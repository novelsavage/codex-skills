# unipa

`unipa` は、麗澤大学の UNIPA / Universal Passport RX を Codex の Chrome 操作で扱うためのスキルです。

UNIPA には、AI エージェントが安定して使える公開 API がありません。
そのため、このスキルでは、Chrome 上に表示された画面を慎重に読み取りながら操作します。

## できること

- 課題の確認
- 授業資料の確認
- 添付ファイル名の確認
- クラスプロファイルの確認
- 課題提出の準備

Windows の Chrome で UNIPA からファイルをダウンロードした場合、通常はユーザーの `Downloads` フォルダに保存されます。

## 重要な設計方針

- ブラウザの戻るボタンを使わない
- 同じ UNIPA セッションを複数タブで扱いすぎない
- パスワードやhidden session値を読まない
- Chrome が Windows Hello によるパスワード入力確認を求めた場合は、ユーザー本人が PIN や生体認証を行う
- `確定`、`提出`、`一時保存`、`送信` などの最終操作はユーザー確認後に行う
- URLやページタイトルではなく、画面本文・授業名・選択状態を優先して判断する

## 麗澤大学 UNIPA での検証

このスキルは、麗澤大学の UNIPA 環境で観察した以下のような画面構造をもとにしています。

- ポータルトップ
- 時間割
- クラスプロファイル
- 課題提出
- 授業資料一覧
- 添付資料確認

他大学の UNIPA でも似た構造がある可能性はあります。
ただし、大学ごとに画面構成やメニュー名が違う場合があります。

## 使い方例

```text
$unipa 今日の授業資料を確認して
```

```text
$unipa ソフトウェア開発の実際の課題を確認して
```

```text
$unipa このPDFを課題に提出する準備をして
```
