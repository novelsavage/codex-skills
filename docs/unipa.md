# unipa

`unipa` は、麗澤大学のUNIPA / Universal Passport RXをCodexのChrome操作で扱うためのスキルです。

## できること

- 課題の確認
- 授業資料の確認
- 添付ファイル名の確認
- クラスプロファイルの確認
- 課題提出の準備

## 重要な設計方針

- ブラウザの戻るボタンを使わない
- 同じUNIPAセッションを複数タブで扱いすぎない
- パスワードやhidden session値を読まない
- `確定`、`提出`、`一時保存`、`送信` などの最終操作はユーザー確認後に行う
- URLやページタイトルではなく、画面本文・授業名・選択状態を優先して判断する

## 麗澤大学UNIPAでの検証

このスキルは、麗澤大学のUNIPA環境で観察した以下のような画面構造をもとにしています。

- ポータルトップ
- 時間割
- クラスプロファイル
- 課題提出
- 授業資料一覧
- 添付資料確認

他大学のUNIPAでも似た構造がある可能性はありますが、大学ごとに画面構成やメニュー名が違う場合があります。

## 使い方例

```text
$unipa 今日の授業資料を確認して
```

```text
$unipa ソフトウェア開発の実際の課題を確認して
```

```text
$unipa このPDFを課題に提出する準備をして
```

## 公開時の注意

IssueやPull Requestでは、以下を貼らないでください。

- 学籍番号
- 氏名
- ログイン情報
- 課題本文の全文
- 授業資料そのもの
- スクリーンショット内の個人情報
