# Mori UI スタイル原則

## 目次

1. 判断の優先順位
2. 主役から画面を作る
3. 題材を部品へ翻訳する
4. 情報密度を用途で変える
5. 境界と形状に意味を持たせる
6. 色・文字・動きを役割化する
7. 参照作品から読み取れる傾向

## 1. 判断の優先順位

衝突した場合は次の順で判断する。

1. 今回ユーザーが明示した要望
2. 現プロジェクトで既に承認されたUI
3. ユーザーが今回提示した参考
4. このスキルの原則
5. リポジトリに残る過去の実装
6. 一般的なデザイントレンド

このスキルはMoriの好みを助けるが、現在の指示を上書きしない。

## 2. 主役から画面を作る

レイアウトを先に選ばない。画面の仕事と主役を特定し、主役に最大の面積・最短の操作経路・最も強い視覚階層を与える。

- 探索: 地図、グラフ、タイムラインをキャンバスとして広く使う
- 運用: 対象一覧、現在状態、次の操作を近づける
- 入力: 入力対象と検証結果を同じ文脈で見せる
- 読解: 文章や資料を主役にし、操作を静かに退避する
- 監視: 数値だけでなく、変化・原因・処置への導線を示す

タイトルとカード群だけで画面を埋めない。主役のない画面は、装飾を増やしても固有性を得られない。

## 3. 題材を部品へ翻訳する

題材固有の物理性、記号、手順、関係をUIへ変換する。

| 題材 | 翻訳できる要素 | 避けたい短絡 |
|---|---|---|
| 地図・記憶 | 座標、方位、ピン、レイヤー、距離、経路 | 地図を小さなカードへ閉じ込める |
| OCR・資料整理 | 紙面、付箋、処理キュー、信頼度、確認待ち | アップロードを派手なヒーローにする |
| 音・関係グラフ | ノード、接続、波形、ログ、選択対象 | 棒グラフを3枚並べて済ませる |
| 伝達・運用 | 合図、優先度、担当、期限、到達状態 | 抽象的な「つながる」コピーにする |

表層的な擬物化ではなく、判断や操作に役立つものだけ採用する。

## 4. 情報密度を用途で変える

「余白が多いほど上質」とは限らない。

- 管理画面: 行間を詰め、比較可能な列と状態を保つ
- 作業画面: 一つの主要操作を明確にし、補助情報を近接させる
- 探索画面: 主役を全面化し、HUDを端へ寄せる
- 読書画面: 行長、段落間隔、文字サイズで読みやすさを作る
- モバイル: 重要度で再構成し、横幅の不足をカード乱造で逃げない

## 5. 境界と形状に意味を持たせる

区切りには、余白、罫線、背景差、位置、見出し階層を使える。すべてを角丸カードへ入れない。

カードが妥当なのは、対象が独立し、選択・比較・移動・開閉の単位になるとき、またはフォームや要約が意味的に自己完結し、境界によって理解しやすくなるとき。影は浮遊階層やフォーカスを表すとき。角丸はシャッター、アバター、チップなど形状や操作上の理由があるときに使う。

角丸カードの上辺だけをアクセント色にするなど、輪郭の一部を着色する場合も意味が必要になる。選択、警告、分類を一貫して表すのでなければ、通常の境界線へ戻すか、余白と見出し階層で区切る。

紙や付箋を表す場合、均一なソフトシャドウより、硬いオフセット影やずれのほうが題材と整合することがある。

## 6. 色・文字・動きを役割化する

### 色

色は識別と状態へ使う。アクセント色を面積いっぱいに塗らず、主操作、選択、警告など役割を限定する。暗色と蛍光緑は過去作品に見られるが、固定テーマではない。

### 文字

- 本文: 長時間読める字形と行間
- 見出し: 内容の区切りを示す強さ
- 数値・ID: 桁や記号を比較しやすい等幅系
- 表示書体: 短い識別子やタイトルだけ

すべてをディスプレイ書体にしない。日本語縦組みは、文化的・編集的な必然性がある場面で使う。

### 動き

動きは、選択、遷移、因果、進行状況を伝える。全要素を順番にフェードインさせるだけの演出は避ける。`prefers-reduced-motion` に対応する。

## 7. 参照作品から読み取れる傾向

以下はコピー対象ではなく、判断傾向の資料。

- `2026HCD-memory-map-web`: 地図を主役にし、操作をHUDとして重ねる
- `2026HCD-memory-map-ocr`: 付箋、グリッド、処理ステータスで作業の物理性を出す
- `Audiograph-DataVisualization`: グラフを大きく取り、操作パネルとログを周囲に置く
- `Noroshi_Reboot`: 強いタイポグラフィと文化的なモチーフを画面の骨格にする

共通して重要なのは「同じ見た目」ではなく、主題を全面に出し、用途に合わせて密度を変え、装飾にも理由を持たせること。
